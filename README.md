# Coffee Shop Landing Page

## Project Description
The Coffee Shop Landing Page is a beginner-level web development project for Semester 1 B.Tech Computer Science. It aims to create an attractive and user-friendly landing page for a coffee shop using HTML, CSS, and basic JavaScript.

## Technologies Used
- HTML — webpage structure
- CSS — styling, layout, hover effects, and responsive design
- JavaScript — menu toggle and order confirmation

## Planned Features
- Hero banner section
- Coffee menu highlight cards
- Toggle between Hot Drinks and Cold Drinks
- Order Now button with a confirmation message
- Static map placeholder for the shop location
- Warm brown and cream colour theme
- Responsive hero section and hover effects

## Project Structure

- `index.html` — webpage structure
- `style.css` — website styling
- `script.js` — interactive features

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

The website will run locally in the browser.
